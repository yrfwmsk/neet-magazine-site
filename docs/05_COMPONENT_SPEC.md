# コンポーネント仕様

## 基本方針

UI部品は再利用可能なコンポーネントとして管理する。

---

# Header

役割：

全ページ共通ナビゲーション。

表示：

- ロゴ
- メニュー
- テーマ切替

---

# Footer

表示：

- コピーライト
- SNS等リンク
- 問い合わせリンク

---

# ThemeToggle

役割：

ライト・ダークモード切替。

要件：

- 現在状態表示
- 設定保存
- OS設定対応

---

# MagazineCard

役割：

雑誌一覧表示。

表示：

- 表紙
- Vol番号
- タイトル
- 発行日

---

# ArticleCard

役割：

記事一覧表示。

表示：

- タイトル
- 著者
- タグ

---

# SearchBox

役割：

記事検索。

検索対象：

- タイトル
- 本文
- 著者
- タグ

---

# PDFViewer

役割：

冊子PDF閲覧。

技術：

PDF.js

機能：

- ページ移動
- 拡大縮小
- スマホ対応

ダウンロードボタンは表示しない。

---

# Footnote

役割：

記事注釈表示。

仕様：

クリックするとポップオーバー表示。

---

# EventCard

役割：

イベント一覧表示。

表示：

- イベント名
- 日付
- 場所

---

# ContactForm

役割：

応募・お問い合わせ。

種類：

- メンバー応募
- 乱入寄稿
- 感想
- 問い合わせ

送信先は共通。
