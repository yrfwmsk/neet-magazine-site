# Cursor開発ルール

## 1. 基本方針

このプロジェクトは長期運用する公式サイトである。

短期的な実装速度より、保守性と理解しやすさを優先する。

---

# 2. コード方針

- シンプルな実装を優先する
- 不要なライブラリ追加は禁止
- 既存設計を尊重する
- コンポーネント化する

---

# 3. 技術方針

使用：

- Astro
- TypeScript
- Tailwind CSS
- MDX

Reactなど別フレームワークへの変更は禁止。

---

# 4. コンテンツ管理

記事・雑誌・イベント情報はContent Collectionsで管理する。

ページへ直接文章を書き込まない。

記事本文の段落・余白ルールは `docs/07_ARTICLE_SPACING.md` を参照する。

---

# 5. デザイン

白黒基調。

派手な装飾は禁止。

読みやすさを最優先する。

---

# 6. 実装前確認

大きな変更を行う場合：

- 目的
- 影響範囲
- 既存機能への影響

を説明してから実装する。

---

# 7. 不明点

推測で大きな仕様変更をしない。

不明な場合は質問する。

---

# 8. Git

変更単位を小さくする。

意味のある単位でcommitする。

例：

- add search feature
- improve article layout

など。
