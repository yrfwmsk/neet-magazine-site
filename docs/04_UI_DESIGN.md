# ニートマガジン公式サイト UIデザイン仕様

## 1. デザインコンセプト

「紙の雑誌を読む体験」と「Webアーカイブ」を両立する。

方向性：

- ミニマル
- 白黒
- 余白重視
- 装飾過多にしない
- 長期間利用できるデザイン

---

# 2. カラーテーマ

## Light Mode

- 背景：白
- 文字：黒
- 補助色：グレー

## Dark Mode

- 背景：黒
- 文字：白
- 補助色：グレー

テーマ切替ボタンを配置する。

---

# 3. Typography

基本方針：

- 可読性優先
- 長文閲覧に適した文字サイズ
- 日本語文章を快適に読むことを重視

記事本文：

- 行間を広めに設定
- 横幅を制限する

---

# 4. Layout

基本構成：

Header

↓

Main Content

↓

Footer

中央寄せ。

記事ページは文章閲覧を優先する。

---

# 5. Responsive

スマートフォン表示を優先する。

対応：

- PC
- Tablet
- Mobile

---

# 6. アニメーション

不要な演出は避ける。

使用する場合：

- テーマ切替
- モーダル表示
- ページ遷移

など最低限にする。

---

# 7. 雰囲気

参考イメージ：

- 文芸誌
- ZINE
- アーカイブサイト
- 個人出版物

企業LPのような派手さは避ける。
